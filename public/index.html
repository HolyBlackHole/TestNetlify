怎么用它验证部署

  1. 把本目录内容推到 GitHub 仓库的 public/，或直接放仓库根目录并改 netlify.toml。
  2. 在 Netlify 连接该仓库，Build command 留空，Publish directory 填 public。
  3. 部署成功后，把 public/index.html 里的版本号改成 v2 再 push 一次。
  4. 等 Netlify 构建完成（一两分钟内），刷新线上页面：版本号变成 v2 即表示 CD 打通。
